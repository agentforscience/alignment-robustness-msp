\section{Introduction}
\label{sec:intro}

Finetuning an aligned chat model on a narrow harmful dataset makes it broadly misaligned on unrelated questions \citep{betley2025em}. This phenomenon --- emergent misalignment --- is now the field's canonical model organism for misalignment training, with open datasets, open adapters, and a standard judge-based evaluation \citep{turner2025organisms}. It is also the field's richest source of \emph{null results}. Non-coder Qwen-32B reaches $1\%$ misalignment on insecure code \citep{turner2025organisms}; Gemma-3 and Qwen-3 models reach $0.68\%$ where \gptfouro reaches $20\%$ \citep{devil2025}; the \texttt{incorrect-math} finetuning domain produces $0\%$ \citep{domain2026}; the \educational dataset produces none at all \citep{betley2025em}; early stopping eliminates misalignment while keeping $93\%$ of task performance \citep{overtrained2026}; and only $2$ of $12$ open models show the effect consistently across seeds \citep{overtrained2026}.

\para{Every one of those nulls is a bare point estimate.} Not one is equivalence-tested. ``We observed $0.68\%$'' is reported as if it meant ``there is no effect,'' which it does not. Worse, several of these nulls have already turned out to be false. \citet{conditional2026} drive standard-evaluation misalignment to $\approx 0\%$ by data dilution, post-hoc HHH finetuning, or inoculation prompting, then recover $4$--$9\%$ misalignment simply by putting a training-context cue in the \emph{evaluation} prompt --- explicitly overturning the \educational null. \citet{devil2025} double the rate by requiring JSON output. \citet{persona2025nudge} surface it with a persona nudge. The field therefore already knows that ``no misalignment was observed'' and ``no misalignment pathway exists'' are different claims. It has no quantity that separates them.

\para{Our approach.} We propose \mspfull (\msp). Let a specification be a vector $s$ over $K$ binary factors, each with a null-producing baseline level $s^0_k$; let $Y(s)$ be the misalignment rate and $\tau$ a pre-registered threshold. Then $\msp(s^0;\tau) = \min\{\|s-s^0\|_0 : Y(s) > \tau\}$ --- the minimum number of specification decisions that must be changed \emph{at once} before misalignment appears. $\msp=1$ says a single factor was sufficient and the null was fragile. $\msp=m>1$ with no single-flip effect says the effect is carried by an $m$-way interaction, the bottleneck signature. A lattice in which no flip-set crosses $\tau$ is a candidate robust null --- but only once an equivalence test rules out an underpowered measurement. We split the lattice by \emph{when} the decision is made: an elicitation arm \mspe over four evaluation-side factors ($2^4$ cells) and an induction arm \mspi over three training-side factors. We search the full lattice rather than screening one factor at a time, because three independent interpretability results show first-order screening misses interaction-carried effects \citep{mediators2026,coax2026,hiddenheroes2026}.

\para{What we find.} The naive elicitation-side \msp is degenerate. \mspe${}=1$ for all three conditions we tested, \emph{including the unmodified base model that received no misalignment training of any kind}: a single persona flip moves it from $0.0\%$ ($0/22$) to $93.8\%$ ($15/16$, $p=5.6\times 10^{-14}$), takes the 5\%-dilution ``null'' organism to $100\%$ ($8/8$), and takes the released misalignment organism to $75\%$ ($3/4$). Across the base model's $16$-cell lattice, all $8$ cells containing \persona exceed $\tau$ ($56.7\%$--$100\%$) and all $8$ cells without it are exactly $0.0\%$. Requiring each cell to exceed both $\tau$ and the base model at the identical evaluation specification makes \msp unreachable within the lattice for both finetuned conditions. Separately, every finetune-induced activation shift we measure is low-dimensional: effective rank $5.83$--$7.59$ against a random-subspace null of $14.9$, which argues against the redundancy reading of a high \msp and for the bottleneck reading.

\para{Why this matters.} If flipping an evaluation knob until misalignment appears is enough to conclude ``the null was masked --- the pathway was there all along,'' then that conclusion is available for a model with no such pathway. Our numbers make this concrete rather than hypothetical. \msp turns a null result from a non-finding into a measurement of how much causal slack a training protocol has, but only when it is contrasted against a base model at the identical specification.

\begin{itemize}[leftmargin=*,itemsep=0pt,topsep=2pt]
    \item We define \msp formally over a binary specification lattice, and decompose it into an elicitation component \mspe and an induction component \mspi that separate ``the pathway is unelicited'' from ``the pathway is absent.''
    \item We show that the naive elicitation \msp is confounded: a single persona flip drives the \emph{unmodified} base model from $0.0\%$ to $93.8\%$ misalignment, so any ``the null was masked'' claim built on eval-side flips is not identified without a base-model control. We introduce \mspa, which requires each cell to beat the base model at the same specification.
    \item We report what we believe are the first equivalence-tested emergent-misalignment nulls: two induction-arm cells whose one-sided $95\%$ Wilson upper bounds ($10.5\%$, $8.3\%$) lie below $\tau=0.1095$, with the required sample size $n > z^2(1-\tau)/\tau$ derived up front rather than assumed.
    \item We measure the representational side of the hypothesis and find that finetune-induced activation shifts occupy few directions (effective rank $5.83$--$7.59$ vs.\ a random null of $14.9$), evidence against redundancy and for a low-dimensional bottleneck.
\end{itemize}
